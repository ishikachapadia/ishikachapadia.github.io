# Ishika Chapadia — Portfolio

Personal portfolio of **Ishika Chapadia**, Junior Front-End Developer based in
Oshawa, Ontario. Durham College Web Development graduate (2026).

**Live:** https://ishikachapadia.github.io

Hand-coded static site — semantic HTML, custom CSS, and vanilla JavaScript —
with a case-study page for each featured project:

- **Fiaschetteria Rosetta** — client website for an Italian eatery & market in Brooklin (live at fiaschetteriarosetta.com)
- **Thrive Wellthy** — Shopify e-commerce build for a wellness brand
- **Reactor Run** — browser game · **Scratch & Win** — React promo platform
- **Cineview** — movie discovery app · **Kiosk Interface** — touchscreen kiosk UI
- **Field Standard** and **Nekree Grocery** — data-driven PHP builds (case study + code)

## Structure

- `index.html` — home, work index, skills, about, contact
- `*.html` — one case-study page per project
- `css/`, `js/` — styles and scripts
- `assets/` — project imagery and resume
