01 — Project Overview

The Vision

Nekree Grocery is a specialized tool designed to bridge the gap between store flyers and meal planning. Instead of manual browsing, it aggregates live product data from multiple stores within a specific postal radius, allowing users to build meals based on real-time availability and cost.

The interface focuses on high-density data visualization, using a "neobrutalist" design system to make complex nutritional and pricing information digestible at a glance.

Core Features
Postal-Radius Search, Multi-Store Comparison, Automated Macro Tracking
Tech Stack
React, Grocery Data API, CSS Grid
02 — Functional Core

From Data to Plate

03 — Challenges

Solving Fragmentation

The Problem

Fragmented Store Data

Users waste hours checking separate flyers for No Frills, Superstore, and Sobeys. Nutritional info is rarely visible until you hold the physical product.

  • Price variance across locations was hidden from the user
  • No way to estimate a meal's cost and nutrition simultaneously
  • Cluttered retail sites make rapid data-driven shopping impossible
The Solution

Unified Grocery Explorer

A high-performance dashboard that strips away retail fluff to focus on raw product specs and availability.

  • Direct multi-store inventory cross-referencing
  • Live "Recalculate Meal" function for instant cost/health auditing
  • Clean, scan-friendly neobrutalist UI for desktop and mobile efficiency
